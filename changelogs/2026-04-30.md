# Changelog — April 30, 2026

## New Models

### DeepSeek-V4-Pro
DeepSeek released V4-Pro, the largest open-weight model at 1.6T total parameters with 49B active. It achieves GPQA Diamond 90.1%, SWE-bench Verified 80.6%, LiveCodeBench 93.5%, and Codeforces rating 3206—the strongest open model for competitive programming. Terminal-Bench 2.0 scores 67.9%. The model uses a hybrid attention architecture (CSA + HCA) for efficient 1M-token context handling. API pricing: $1.74/M input, $3.48/M output (75% off introductory). MIT license with weights on HuggingFace. [Source](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro)

### DeepSeek-V4-Flash
A more efficient 284B/13B MoE variant achieving GPQA 88.1%, SWE-V 79.0%, and LiveCodeBench 91.6%. Priced at $0.14/M input, $0.28/M output—undercutting GPT-5.4 Nano, Gemini 3.1 Flash, and Claude Haiku 4.5. 1M context window. MIT license. [Source](https://api-docs.deepseek.com/news/news260424)

### Ling-2.6-1T
Ant Group open-sourced its trillion-parameter flagship model with 63B active parameters. Uses MLA + Linear Attention hybrid architecture for 'fast thinking'—achieving flagship-level reasoning with ~1/4 the token cost. SWE-bench Verified SOTA, strong AIME26 results. 1M native context (256K exposed via API). MIT license. Free preview available on OpenRouter; paid tier $0.30/M input, $2.50/M output via Novita AI. [Source](https://developer.ant-ling.com/en/docs/models/ling)

### Ling-2.6-flash
A 104B/7.4B MoE model focused on token efficiency. Artificial Analysis Intelligence Index 26.2. SWE-V 61.2%. AIME26 73.85%. BFCL-V4, TAU2-bench, Claw-Eval, PinchBench at or near SOTA. Peak 340 tokens/s on 4x H20 GPUs. 256K context. MIT license. Previously tested anonymously as 'Elephant Alpha' on OpenRouter where it trended for consecutive days. Pricing: ~$0.08/$0.24 via providers. [Source](https://openrouter.ai/inclusionai/ling-2.6-flash)

### DeepSeek R2
A 32B dense reasoning model that scores 92.7% on AIME 2025 and 99.1% on MATH-500. Runs on a single RTX 4090 (24GB VRAM). GPQA 78.4%. Approximately 70% cheaper than Western frontier reasoning APIs. MIT license with open weights. Strategic pivot from previously-rumored 1.2T MoE architecture to efficient dense design. [Source](https://decodethefuture.org/en/deepseek-r2-explained/)
