# Changelog — April 29, 2026

## New Models

### GPT-5.5
OpenAI released GPT-5.5 on April 23, 2026, their newest frontier model. It scores 60 on the Artificial Analysis Intelligence Index — a new record, three points above the previous 57 ceiling shared by GPT-5.4, Gemini 3.1 Pro, and Claude Opus 4.7. Key benchmarks: Terminal-Bench 2.0 at 82.7% (new SOTA), SWE-Bench Pro at 58.6%, GPQA Diamond 93.6%, OSWorld-Verified 78.7%, GDPval 84.9%, FrontierMath Tier 4 at 35.4%. The model matches GPT-5.4 per-token latency while using significantly fewer tokens per task. API pricing: $5/$30 per 1M tokens with a 1M context window. ([openai.com](https://openai.com/index/introducing-gpt-5-5/))

### GPT-5.5 Pro
Launched alongside GPT-5.5, the Pro variant uses parallel test-time compute for harder problems. FrontierMath Tier 4 reaches 39.6% (nearly 2x Claude Opus 4.7's 22.9%). BrowseComp 90.1%, HLE no-tools 43.1%. Priced at $30/$180 per 1M tokens. Available in ChatGPT for Pro/Business/Enterprise users and via API. ([openai.com](https://openai.com/index/introducing-gpt-5-5/))

### Kimi K2.6
Moonshot AI released Kimi K2.6 on April 21, 2026 — the first open-weight model to tie GPT-5.5 on SWE-Bench Pro at 58.6%. Additional benchmarks: SWE-Bench Verified 80.2%, LiveCodeBench v6 89.6%, HLE with tools 54.0%, Terminal-Bench 2.0 66.7%. Built on the same 1T/32B MoE architecture as K2.5 but with dramatically improved tool use (Toolathlon 50.0% vs K2.5's 27.8%). Supports 300-agent swarms and 12-hour autonomous runs. Open-weight base under Apache 2.0. ~$0.60/$3.00 via providers. ([kimi.com](https://www.kimi.com/blog/kimi-k2-6))

### Qwen3.6-27B
Alibaba released Qwen3.6-27B on April 22, 2026, a dense 27B-parameter model that beats its 397B MoE predecessor on every major coding benchmark. SWE-Bench Verified 77.2% (vs 397B's 76.2%), SWE-Bench Pro 53.5%, Terminal-Bench 2.0 59.3%, GPQA Diamond 87.8%. Uses a novel Gated DeltaNet + Gated Attention hybrid architecture. 262K context window extensible to 1M. Apache 2.0 license. A 4-bit quantization runs in ~17 GB. ([alibabacloud.com](https://www.alibabacloud.com/blog/qwen3-6-27b-flagship-level-coding-in-a-27b-dense-model_603063))

### Nemotron 3 Nano Omni
NVIDIA released Nemotron 3 Nano Omni on April 28, 2026 — an open multimodal model combining video, audio, image, and text understanding in a single 30B/3B MoE architecture. It delivers 9.2x higher throughput than other open omni models at the same interactivity. OSWorld 47.4%, ScreenSpot-Pro 57.8%, Video-MME 72.2%, VoiceBench 89.4%. Tops six industry leaderboards. Open weights. Designed as the perception layer for multimodal AI agents. ([nvidia.com](https://blogs.nvidia.com/blog/nemotron-3-nano-omni-multimodal-ai-agents/))

### Granite 4.1 30B
IBM released the Granite 4.1 family on April 29, 2026, with language models in 3B, 8B, and 30B sizes. The 30B scores MMLU 80.2%, HumanEval 88.4%, BFCL v3 73.7%. The 8B matches the previous-generation 32B MoE on instruction following and tool calling. All dense decoder-only architecture, 131K context. Also released: Granite Vision 4.1, Speech 4.1, Guardian 4.1, and Embedding R2. Apache 2.0. ([ibm.com](https://research.ibm.com/blog/granite-4-1-ai-foundation-models))
